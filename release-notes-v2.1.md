# Nomi v2.1

This release adds a diary export so you can take a day's foods, calories, protein and carbs out of Nomi as JSON.

- **Settings → Your data → Export diary** writes a pretty-printed JSON file of every logged day.
- Each day has its date, the foods you ate (name, brand, amount, unit and meal), and that day's calorie, protein and carbohydrate totals.
- Each food also carries its own kcal, protein and carbs, so the day total matches the items.
- The diary is not a backup: it does not restore into Nomi, and it does not contain API keys, profile data or the food catalog. **Export backup** is still the full restoreable copy.

The APK is signed with the same certificate as prior stable releases.
