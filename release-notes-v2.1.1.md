# Nomi v2.1.1

This release lets you log food from Google Assistant and opens the camera from a long-press on the app icon.

- Say “add a banana in Nomi” (or “füge eine Banane hinzu”) and Nomi researches it, logs it, then answers with the calories left today.
- Ask “how many calories left in Nomi” to hear today’s remaining budget without logging.
- Long-press the Nomi icon for **Photo** or **Menu**.

The APK is signed with the same certificate as prior stable releases.
