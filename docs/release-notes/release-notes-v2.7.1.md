# Nomi v2.7.1

- Sharing and receiving now live in the bottom **+** menu, making receiving available even on an empty day.
- Choose **Share**, check one or more foods from the displayed day, then **Tap to share**. Select all and optional totals are still available.
- Removed sharing actions from entry long-press menus.

Install the attached APK over your existing Nomi installation to keep your data.
