# Nomi v2.7.2

- Swipe left on a favorite or saved meal to delete it, with a red delete reveal and haptic feedback.
- A short inline Undo window lets you cancel accidental deletions, even after switching library tabs.
- Removing a favorite or saved meal keeps your logged diary entries intact.
- Screen-reader users can use the Delete accessibility action.

Install the attached APK over your existing Nomi installation to keep your data.
