# Nomi v2.3.0

- The welcome screen now demonstrates what Nomi does, in a short animated sequence: a meal is written in plain language, split into separate foods with real weights, totalled, and shown with where its numbers came from.
- The demo names all three other ways in — take a photo of your plate, scan a barcode, read a nutrition label — with the food rows and the total held still underneath, because the point is that every route lands on the same precise answer.
- Every quantity in the demo is a real weight in grams, and the figures are the typical values for the foods as described. The card is labelled as an example so it cannot be mistaken for a measurement.
- The sequence plays once in about 3.6 seconds, can be skipped with a tap anywhere on the card, and never plays at all when the system animation scale is set to zero.
- Nomi now respects the system animation scale, which it previously ignored everywhere.
- The welcome screen's fox logo uses a neutral theme tone instead of a hard-coded cream that only looked right in light mode.
- New copy in all ten languages.
