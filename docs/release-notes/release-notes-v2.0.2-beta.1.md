## Nomi 2.0.2 Beta 1

Nomi keeps the same navigation, screen structure and low-friction logging flow, now with a more cohesive Material 3 finish.

### What changed

- A refreshed warm fallback palette pairs Nomi orange with sage and soft gold; wallpaper-based dynamic color still works as before.
- Typography has a clearer hierarchy while retaining Android's system font and the same text sizes.
- Cards, settings rows, picker fields and selection states now share crisper surfaces across light, dark and pitch-black themes.
- Today transitions smoothly between writing, researching, reviewing and error states, and date changes move in the correct direction.
- Press feedback and destination selection use Material's standard motion instead of a lingering bounce.
- Progress and Settings use subtle destination tones, and the weight chart now reveals with a soft area fill and dashed goal marker.
- The food library shows the selected category and its category chips scroll horizontally for long labels.
- System-bar icon contrast follows Nomi's in-app theme selection.

### Beta note

This prerelease is a visual and interaction preview. It does not migrate or change saved nutrition data, AI providers or research behaviour.

### Compatibility

- Existing food logs, goals, provider settings and backups are unchanged.
- Android 8.0 and newer remain supported.
