# Nomi v2.14.4

### Consistent meal processing cards

- Editing an existing meal now shows the same Material 3 Expressive processing card as logging a new meal.
- Text editing, cancellation, and research sources remain available during edits. The background-processing hint is only shown for queued meals.

Install `Nomi-v2.14.4-release.apk` over the phone app to keep your data. The matching Wear OS APK is `Nomi-v2.14.4-wear-release.apk`.
