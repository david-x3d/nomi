## Nomi 2.0.1

Grouped meals can now be rewritten as naturally as single foods.

### What changed

- Tap the name on the left of a grouped meal to reopen it in the inline text editor.
- New entries retain the exact typed or dictated sentence, including every item and amount.
- Older grouped entries rebuild editable text from all stored items, so they are not left behind.
- Change items or quantities and submit again; Nomi replaces the complete old group with the newly researched result.
- The meal stays in its original breakfast, lunch, dinner or snack category while editing.
- Tapping the calorie value continues to open the nutrition details.
- The database upgrades safely and backups include the stored original input.
