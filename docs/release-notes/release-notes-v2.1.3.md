# Nomi v2.1.3

This release removes Gemini and Assistant food logging. Google does not let a sideloaded app appear in Gemini’s Connected Apps list.

- Long-press the Nomi icon for **Photo** or **Menu**. That stays.
- “Add a banana in Nomi” through Gemini or Assistant is gone.

The APK is signed with the same certificate as prior stable releases.
