# Nomi v2.12.0

### A new look for Settings, inspired by Wisp

- Settings rows are now grouped into tiles with large outer and small inner corners, on a soft tonal page.
- Row icons sit in tonal badges with expressive shapes, and section titles use the accent colour.
- The whole app now uses the Outfit typeface and larger corner radii; characters Outfit lacks fall back to the system font.
- Sub-pages use a tonal back button.

Install `Nomi-v2.12.0-release.apk` over the phone app to keep your data. Install `Nomi-v2.12.0-wear-release.apk` on the watch using Wi-Fi debugging (`adb install`) or a sideloading app such as Wear Installer. Both APKs use the existing signing key.
