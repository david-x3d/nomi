# Nomi v2.7

- Hold a food entry and choose **Share multiple** to select foods from the displayed day, then tap to share over NFC.
- The held entry starts selected. Check individual foods, select all or clear the selection, and optionally include totals for only the selected foods.
- Fixed GitHub release parsing so available updates can appear in the update popup.
- Nomi checks for updates on every app start and return to the foreground, without blocking startup.

Install the attached APK over your existing Nomi installation to keep your data.
