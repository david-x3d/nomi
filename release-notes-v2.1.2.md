# Nomi v2.1.2

This release lets Gemini log food in Nomi instead of dumping it into Google Keep.

- Say “add a banana in Nomi” (or “füge eine Banane in Nomi hinzu”). Gemini calls Nomi, Nomi researches and logs it, then Gemini hears the calories left today.
- “How many calories left in Nomi” answers from the local diary without logging.
- Needs Android 16+. The first time, allow Nomi when Gemini asks to use the app.

The APK is signed with the same certificate as prior stable releases.
